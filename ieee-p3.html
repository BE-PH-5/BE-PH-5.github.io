Project 3 — Auto Trashcan

ESP32HC-SR04Servo
What I Built

A trash can that opens its lid automatically when a hand gets close. An HC-SR04 ultrasonic sensor measures distance continuously, and when something crosses the set threshold, the firmware triggers an SG90 servo to open the lid. The lid stays open while the object is still in range and closes once it moves away.

How the Sensor Works

The HC-SR04 fires a short ultrasonic pulse on the trigger pin and then listens for the echo to return. The time between sending and receiving that pulse tells you how far away the object is. The formula is distance in cm = duration / 58.0. The firmware checks this value in a loop and compares it against a threshold to decide whether to open or close the lid.

Manual Mode First

Built and tested a manual control mode before writing the automatic version. Having manual control meant I could verify the servo was wired and coded correctly before adding the sensor logic on top. Saved time debugging.

What Was Hard

Setting the right distance threshold took a lot of testing. Too sensitive and the lid would flutter open and closed for no reason. Too conservative and it barely responded when you actually put your hand near it. Had to do a lot of repetitive hand-waving to land on a value that felt right.
