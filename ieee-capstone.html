Capstone — RC Rover

ESP-NOWL293DCustom PCBCapstone
What I Built

A two-ESP32 RC rover system. One ESP32 lives on a custom PCB joystick remote I designed in KiCad. The other drives the rover through an L293D motor controller. The two talk over ESP-NOW. Two operating modes: manual joystick control and autonomous obstacle avoidance with an HC-SR04.

Custom PCB Remote

Designed the joystick remote PCB in KiCad using the same workflow as Project 8. The board has an analog joystick with VX and VY outputs connected to two ADC pins on the transmitter ESP32. The ESP32 reads both axes, packs them into a struct, and sends the struct to the rover's MAC address over ESP-NOW.

L293D Motor Driver

Read the L293D datasheet to figure out the pinout and how the enable and direction pins work. The IC has two H-bridges, one per motor. Setting the direction pins determines which way each motor spins, and the enable pins accept PWM for speed control. Wrote motor control functions from what the datasheet described, then tested each motor separately before combining into differential drive.

Autonomous Mode

Added an HC-SR04 on the rover for obstacle detection. In autonomous mode the rover drives forward until the sensor reads below the threshold distance, then turns to avoid the obstacle. A button on the remote toggles between manual and autonomous, both handled in the same firmware.

What Went Wrong

The joystick readings came in inverted. Had to find the midpoint of each axis and flip the mapping above and below that point. The sensitivity was also way off at first. The rover was jerky since the deadband range around the center was too narrow, and I adjusted it several times before it felt controllable. The wheels also ran in reverse due to a sign error in the motor direction logic. In autonomous mode I set the turn direction wrong, so the rover was driving into obstacles instead of away from them. Fitting manual and autonomous control into one codebase without each breaking the other's state was the hardest part overall.

Rover Firmware

Full ESP32 receiver firmware running on the rover.

#include <WiFiConfig.h> const int LEFT_FWD = 5; const int LEFT_BCK = 6; const int RIGHT_FWD = 7; const int RIGHT_BCK = 8; const int TRIG_PIN = 3; const int ECHO_PIN = 10; // I put my voltage divider here so I don't fry my ESP32! RemoteData data; bool isAutonomous = false; int lastButtonState = HIGH; void setup() { Serial.begin(115200); pinMode(LEFT_FWD, OUTPUT); pinMode(LEFT_BCK, OUTPUT); pinMode(RIGHT_FWD, OUTPUT); pinMode(RIGHT_BCK, OUTPUT); pinMode(TRIG_PIN, OUTPUT); pinMode(ECHO_PIN, INPUT); wifi_setup(); set_data_receiver(&data); data.vx = 202; data.vy = 205; data.sw = 1; } void stopMotors() { digitalWrite(LEFT_FWD, LOW); digitalWrite(LEFT_BCK, LOW); digitalWrite(RIGHT_FWD, LOW); digitalWrite(RIGHT_BCK, LOW); } void moveForward() { digitalWrite(LEFT_FWD, HIGH); digitalWrite(LEFT_BCK, LOW); digitalWrite(RIGHT_FWD, HIGH); digitalWrite(RIGHT_BCK, LOW); } void moveBackward() { digitalWrite(LEFT_FWD, LOW); digitalWrite(LEFT_BCK, HIGH); digitalWrite(RIGHT_FWD, LOW); digitalWrite(RIGHT_BCK, HIGH); } void turnRight() { digitalWrite(LEFT_FWD, HIGH); digitalWrite(LEFT_BCK, LOW); digitalWrite(RIGHT_FWD, LOW); digitalWrite(RIGHT_BCK, LOW); } void turnLeft() { digitalWrite(LEFT_FWD, LOW); digitalWrite(LEFT_BCK, LOW); digitalWrite(RIGHT_FWD, HIGH); digitalWrite(RIGHT_BCK, LOW); } void loop() { if (data.sw == LOW && lastButtonState == HIGH) { isAutonomous = !isAutonomous; stopMotors(); delay(300); } lastButtonState = data.sw; if (isAutonomous) { digitalWrite(TRIG_PIN, LOW); delayMicroseconds(2); digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10); digitalWrite(TRIG_PIN, LOW); long duration = pulseIn(ECHO_PIN, HIGH, 30000); long distance = duration / 58.0; Serial.print("Sensor Distance: "); Serial.print(distance); Serial.println(" cm"); if (distance > 0 && distance < 20) { turnRight(); delay(500); } else { moveBackward(); } } else { if (data.vx < 100) { turnLeft(); } else if (data.vx > 230) { turnRight(); } else if (data.vy < 100) { moveForward(); } else if (data.vy > 230) { moveBackward(); } else { stopMotors(); } } }
Controller Firmware

Full ESP32 transmitter firmware running on the custom PCB joystick remote.

#include <WiFiConfig.h> uint8_t roverAddress[] = {0xA8, 0x46, 0x74, 0x5C, 0x16, 0x50}; const int VY_PIN = 0; const int VX_PIN = 1; const int SW_PIN = 3; const int LED_MANUAL = 8; const int LED_AUTO = 10; RemoteData data; bool isAutonomous = false; void setup() { Serial.begin(115200); pinMode(SW_PIN, INPUT_PULLUP); pinMode(LED_MANUAL, OUTPUT); pinMode(LED_AUTO, OUTPUT); wifi_setup(); peer_setup(roverAddress); digitalWrite(LED_MANUAL, HIGH); digitalWrite(LED_AUTO, LOW); } void loop() { int rawX = analogRead(VX_PIN); int rawY = analogRead(VY_PIN); data.vx = map(rawX, 0, 4095, 0, 255); data.vy = map(rawY, 0, 4095, 0, 255); data.sw = digitalRead(SW_PIN); if (data.sw == LOW) { isAutonomous = !isAutonomous; digitalWrite(LED_MANUAL, !isAutonomous ? HIGH : LOW); digitalWrite(LED_AUTO, isAutonomous ? HIGH : LOW); delay(500); } send_data(roverAddress, data); delay(50); }
