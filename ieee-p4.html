Project 4 — MP3 Player (iPoduino v2.0)

DFPlayer MiniUARTESP32
What I Built

An MP3 player using a DFPlayer Mini module and a microSD card. The ESP32 sends serial commands over UART to control playback: play, pause, skip track, and volume. Loaded it up with Kpop songs.

UART Protocol

UART is an asynchronous serial protocol with no shared clock between the two devices. Each data packet has a start bit, 8 bits of data, an optional parity bit, and a stop bit. Both sides need to be configured to the same baud rate or the data comes through garbled. Used HardwareSerial to open a second UART channel on the ESP32 so the built-in USB serial stayed free for debugging.

Why DFPlayer Mini

The ESP32 doesn't have enough flash memory to store audio files directly. The DFPlayer Mini has its own microSD reader and a built-in audio decoder IC, so it handles all the playback on its own. The ESP32 just sends command packets to it over UART.

Reading the Datasheet

Had to read the DFPlayer Mini datasheet to find the correct pinout and command byte format. The data line also needed an external pull-up resistor, which wasn't mentioned anywhere obvious and took some time to find in the specs. The internal pull-ups on the ESP32 weren't strong enough for this module.
