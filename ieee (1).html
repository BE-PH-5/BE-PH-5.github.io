Breadboard555 TimerSoldering
Projects 1 & 2 — Foundational Electronics
Goal & Motivation
The goal was to learn core electronics fundamentals: breadboarding, reading resistor color bands, applying Ohm's Law to a real circuit, and using the NE555P Timer IC.
How I Fulfilled the Requirements
For Project 1, built a 9V LED circuit on a breadboard: calculated the resistor value using V=IR, then soldered it to perfboard. For Project 2, used the 555 Timer IC to build a blinking LED and a 3-button piano.
Results & Lessons Learned
Both circuits worked. Real components have tolerances and breadboard connections add resistance, so the math alone doesn't always match what you measure. For P2, reading the 555 timer datasheet directly was more useful than following tutorials.

ESP32Ultrasonic SensorServo
Project 3 — Auto Trashcan
Goal & Motivation
Build a sensor-activated trash can that opens its lid when a hand is detected nearby, using an ultrasonic sensor and servo motor.
How I Fulfilled the Requirements
Used an ultrasonic distance sensor to continuously monitor proximity. When an object enters the detection threshold, the firmware triggers a servo motor to open the lid, holds it open while the object remains in range, and closes it once the object moves away. Also built and tested a manual control mode before implementing the automatic behavior.
Results & Lessons Learned
The trashcan opened and closed reliably in automatic mode. Setting the distance threshold took some trial and error. Too sensitive and the lid fluttered; too conservative and it barely triggered.

DFPlayer MiniUARTESP32
Project 4 — MP3 Player
Goal & Motivation
The goal was to build a basic MP3 player using a DFPlayer Mini module and microSD card, using UART to send playback commands from the ESP32.
How I Fulfilled the Requirements
Wired the DFPlayer Mini to the ESP32 via UART and wrote firmware to send serial commands for controlling playback. Implemented controls for play, pause, skip, and volume, testing each function as part of the build process before moving to the final integrated version.
Results & Lessons Learned
Built a working MP3 player. UART needs matching baud rates and correct command framing on both ends — if either is off, the module just ignores the input.

PhotoresistorADCESP32
Project 5 — Photoresistor
Goal & Motivation
The goal was to build a light-sensing circuit using a photoresistor as an analog input read by the ESP32's ADC, and use the light readings to trigger a response.
How I Fulfilled the Requirements
Wired a photoresistor in a voltage divider configuration to create a variable analog voltage that changes with light intensity. Read the output through the ESP32's ADC, mapped the values to a useful range, and used the readings to drive an output response that reacts to ambient light changes.
Results & Lessons Learned
The circuit responded correctly to light changes. A photoresistor needs a companion resistor in a voltage divider to produce a voltage the ADC can actually read. Picking the right value for that resistor needed some testing.

Hardware TimersESP32LED
Project 6 — Timer
Goal & Motivation
The goal was to use the ESP32's hardware timer peripherals instead of software delays, and understand the difference between the two.
How I Fulfilled the Requirements
Configured the ESP32's hardware timer to trigger at precise intervals, driving LED visual feedback tied to the timer events. Tested the timing accuracy and behavior under different configurations to understand how hardware timers operate independently of the main program loop.
Results & Lessons Learned
The timer ran accurately. Software delays block the CPU and can drift; hardware timers run in the background and stay accurate regardless of what the main loop is doing.

Custom PCBESP-NOWL293DCapstone
Project 7 — RC Rover
Goal & Motivation
The capstone: design a custom PCB joystick remote, build a wireless rover driven by an L293D motor controller, and implement manual control via ESP-NOW and an autonomous obstacle-avoidance mode.
How I Fulfilled the Requirements
Designed the custom PCB joystick controller and applied the PCB design workflow learned earlier. Used ESP-NOW for low-latency wireless communication between the remote and rover. Programmed the L293D motor driver for differential drive control and implemented both manual joystick driving and an autonomous obstacle-avoidance mode using distance sensors.
Results & Lessons Learned
The rover runs in both manual and autonomous modes. The ESP-NOW link, hardware timers, PCB design, and sensor work from earlier projects all fed into this build directly.

KiCadPCB DesignSchematic
Project 8 — PCB Design
Goal & Motivation
The goal was to design a PCB in KiCad 7.0 for a circuit previously built on a breadboard. This covered the full workflow: schematic, component footprints, PCB layout, trace routing, and ground fill.
How I Fulfilled the Requirements
Completed the full KiCad design flow: drew the schematic with correct net connections, assigned physical footprints to each component, laid out the PCB, routed all signal traces, configured trace widths for current requirements, and added a ground fill plane. Board-reviewed at each stage before moving forward.
Results & Lessons Learned
Completed the full PCB design. Laying out a PCB is a different skill from drawing a schematic. Getting components placed well and traces routed without issues takes more work than the schematic side does.
