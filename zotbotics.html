ZOTBotics Introductory Makerspace · Jan 2026 – Jun 2026

ZOTBotics

Electrical assembly and wiring on a 6-DOF open-source Arctos robotic arm, including a custom claw attachment built to complete three competition tasks.

Arduino MEGA Wiring Competition
Goal & Motivation

The task was to assemble and wire a 6-DOF Arctos robotic arm, then design a claw attachment that could complete three competition tasks: weight lifting, cup stacking, and pouring water between cups.

How I Fulfilled the Requirements

Handled the electrical assembly and wiring of the arm, connecting stepper motors, limit switch sensors, and an Arduino MEGA. Designed a claw attachment that could grip rigid objects and control a tipping motion for pouring. Gave a project presentation covering design decisions and competition results.

What Went Wrong

First test jog had the arm driving in the wrong direction. Instead of tearing apart the wiring harness to swap stepper coil pairs, I fixed it in the firmware using the direction invert mask ($3 setting in GRBL). Gear ratios were the next problem: the Y-axis runs a 150:1 gearbox reduction, and a misconfigured steps-per-degree value caused the arm to wildly overshoot commanded positions. I also had to physically reposition the Hall effect limit switch sensors joint by joint so the homing sequence would cut motor power before reaching the mechanical hard stops, not after.

Results & Lessons Learned

The arm completed all three competition tasks. Small wiring alignment errors created backlash at the end effector, so the electrical and mechanical sides of the build had to be considered together, not separately.

Claw Firmware

Arduino servo code I wrote for the DS3225 gripper on the end effector.

#include <Servo.h> // Creating my servo object to control the Arctos claw gripper Servo myClaw; // Pin setup - I plugged my servo signal wire into digital pin 11 on my Arduino Mega const int SERVO_PIN = 11; // I tweaked these angle values so my printed gripper fully opens and closes without jamming const int OPEN_ANGLE = 20; // My claw's wide open position const int CLOSE_ANGLE = 110; // My claw's fully closed position // Keeping track of where my servo currently is int currentAngle = OPEN_ANGLE; void setup() { // Starting serial communication just in case I need to debug later Serial.begin(9600); // Attaching my servo object to the pin on my board myClaw.attach(SERVO_PIN); // Set the starting position to open so I know it's ready myClaw.write(OPEN_ANGLE); delay(500); } void loop() { // Open the claw smoothly smoothMove(OPEN_ANGLE, 15); delay(2000); // Hold open for 2 seconds // Close the claw smoothly smoothMove(CLOSE_ANGLE, 15); delay(2000); // Hold closed for 2 seconds } // I wrote this function to move the servo gradually. // If I just use write() directly, the DS3225 servo snaps shut way too fast // and shakes my whole robotic arm! void smoothMove(int targetAngle, int stepDelay) { if (currentAngle < targetAngle) { // Stepping up to target position for (int pos = currentAngle; pos <= targetAngle; pos++) { myClaw.write(pos); delay(stepDelay); // Small delay between steps makes it move smoothly } } else { // Stepping down to target position for (int pos = currentAngle; pos >= targetAngle; pos--) { myClaw.write(pos); delay(stepDelay); } } // Remember my new position currentAngle = targetAngle; }
